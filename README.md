# qmt-cb-strategy

国金QMT可转债交易策略（单文件版）。

## 使用方式

1. 修改 `qmt_cb_strategy.py` 顶部的 `ACCOUNT_ID` 为你的国金证券资金账号。
2. 在国金QMT终端【策略开发】中新建Python模型，将 `qmt_cb_strategy.py` 全部内容粘贴进去。
3. K线周期设为 **1分钟**，订阅可转债行情，启动运行。
4. 建议先在模拟盘/回测模式验证。

## 策略特点

- 每天多个固定时点调仓：09:35 / 10:30 / 11:20 / 14:00 / 14:45
- ATR止损 + 固定比率止损
- 最高价跟踪止盈，盈利后不断抬高止盈线
- 组合级风控：单日最大亏损、最大回撤限制
