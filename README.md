# qmt-cb-strategy

国金QMT可转债交易策略（单文件版 v2）。

## 使用方式

1. 修改 `qmt_cb_strategy.py` 顶部的 `ACCOUNT_ID` 为你的国金证券资金账号（或导入XML后在配置面板修改）。
2. 在国金QMT终端【策略开发】中新建Python模型，将 `qmt_cb_strategy.py` 全部内容粘贴进去。
3. **导入XML配置**：在策略编辑器中导入 `qmt_cb_strategy_config.xml`，右侧参数面板即可显示所有可配置项。
4. K线周期设为 **1分钟**，订阅可转债行情，启动运行。
5. 建议先在模拟盘/回测模式验证。

## 配置方式

策略支持两种配置方式：

- **直接修改代码**：编辑 `qmt_cb_strategy.py` 顶部 `_cfg()` 中的默认值。
- **QMT配置面板**：导入 `qmt_cb_strategy_config.xml` 后，在右侧参数面板修改，运行时QMT会自动覆盖代码中的默认值。

## 调仓与风控运行方式

- **K 线周期**：策略需在 **1 分钟周期（分时图）**上运行，`handlebar` 每分钟触发一次，天然实现分钟级风控监控。
- **调仓时间**：由 XML 中的 `REBALANCE_TIMES` 控制，策略 `init` 时用 `ContextInfo.run_time` 注册，每天在指定时间点执行一次调仓。
- **风控监控**：止损、跟踪止盈、组合级风控均在 `handlebar` 中执行，因 1 分钟周期而按分钟运行。
- **算法单**：XML 中 `USE_ALGO_ORDER` 控制是否启用算法单，默认关闭。开启后调用 `algo_passorder`，通过 `userOrderParam` 字典传入拆单参数（`OrderType`、`MaxOrderCount`、`SuperPriceType` 等）；若当前 QMT 版本不支持或调用失败，自动回退到普通 `passorder`。

## 策略特点

### 风控
- ATR止损（2.5倍ATR） + 固定比率止损（2.5%） + 单票最大亏损限制（5%）
- 最小止损幅度保护（2%），防止ATR过窄被洗出
- 最高价跟踪止盈：盈利超2%后启动，最高价回落1.5倍ATR止盈
- 跟踪止盈线只升不降，且不低于成本价（保本）
- 组合级风控：单日亏损4%或总回撤8%时清仓并锁定，次日自动解锁

### 选股
- 双低因子（低价+低溢价）与趋势因子结合
- 均线多头排列、动量、量能突破、RSI、价格分位多维打分
- 正股趋势辅助判断（如QMT接口可获取正股代码）
- 过滤高价妖债、强赎风险债、到期前30天、上市前5天、流动性差标的

### 交易
- 每天5个固定时点调仓：09:35 / 10:30 / 11:20 / 14:00 / 14:45
- 卖出限价自动让利0.2%，提升止损止盈成交概率
- 买入成功后才加入风控器，避免状态不一致
- 状态文件原子写入，策略重启后自动同步持仓（优先使用QMT持仓成本价）

## 参数调整

所有参数集中在文件顶部，可根据风险偏好修改：

- `RISK_CONFIG`：止损止盈、组合风控参数
- `FILTER_CONFIG`：可转债筛选条件
- `SIGNAL_CONFIG`：选股打分参数
- `POSITION_CONFIG`：仓位管理参数
